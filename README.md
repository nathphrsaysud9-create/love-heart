# love-heart

หน้าแอนิเมชันหัวใจจากวลี “I love you” หลายภาษา สร้างด้วย HTML Canvas

- ใช้ 19 วลีจากภาพและนำกลับมาใช้ซ้ำเพื่อเติมรูปหัวใจ
- ใช้สีแดงคอรัลเดิม `#FF544C` พร้อมแสงเรืองสีเดียวกันและปรับความสว่างแต่ละวลีเล็กน้อย
- แคชภาพวลีไว้ใช้ซ้ำ จำกัดการวาดที่ 30 FPS และใช้การจัดลำดับแบบเบาเพื่อลดอาการหน่วง
- เปิดหน้าเว็บ: https://nathphrsaysud9-create.github.io/love-heart/
- รันในเครื่อง: เปิด `index.html` ในเบราว์เซอร์
